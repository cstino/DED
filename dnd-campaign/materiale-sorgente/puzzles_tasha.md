# Puzzles from Tasha's Cauldron of Everything

I have extracted the following puzzles from the "Dungeon Master's Tools" section (Chapter 4) of the manual.

## 🟢 Easy Puzzles

| Puzzle Name | Description | Solution |
| :--- | :--- | :--- |
| **Creature Paintings** | Counting creatures in 7 paintings to reveal letters. | Spell "owlbear" by counting into each name. |
| **Reckless Steps** | A word search on floor tiles featuring schools of magic. | Step only on tiles that DO NOT spell "magic" or a school of magic. |
| **Skeleton Keys** | Matching 4 keys with different teeth counts to 4 creature locks. | Teeth count = # of letters in the creature's name (e.g., Bat = 3). |

## 🟡 Medium Puzzles

| Puzzle Name | Description | Solution |
| :--- | :--- | :--- |
| **All That Glitters** | Counting 9 types of gemstones scattered on the floor. | Convert counts to alphabet letters (1=A, 5=E, etc.) to spell "In her palm". |
| **Eye of the Beholder** | A magical maze guided by an Igor (goblin) with riddles. | First letter of each riddle answer (Eagle, Needle, etc.) = Direction (E, N, W, S). |
| **Four by Four** | A 3x3 grid where 9 dwarf skulls must be placed. | Grid logic: rows/columns must have I, II, or III skulls as labeled. |
| **Illusive Island** | Tracing a 3-day path on a landmark map following a journal. | The path traced on the map reveals three digits (3, 4, 8). |
| **Material Components** | Matching lists of spells to their components. | Connecting lines cross out letters; remaining letters spell "presto". |
| **Members Only** | A password exchange at a guarded door (numeric). | Password = # of letters in the number word given (e.g., "Twelve" -> 6). |

## 🔴 Hard Puzzles

| Puzzle Name | Description | Solution |
| :--- | :--- | :--- |
| **Exact Change** | A coin-based vault lock requiring a 3x3 magic square. | A magic square totaling 15 in all directions. Insert 5 coins (center). |
| **Four Elements** | Fixing a broken row of elemental tiles to keep statues bound. | Recognizing interlaced patterns of triangles (up/down/lined). |
| **Haunted Hallway** | Helping a ghost girl (Dolora) find her doll's name. | Extracting specific letters from names of her past (Doll name: "Sefina"). |
| **What's On the Menu**| Decoding a tavern menu with irregular prices. | Alphabetize menu + count into name by cost = "chimera". |

---
> [!TIP]
> Each of these can be modified to fit your Eberron campaign. For example, "Members Only" is perfect for a **Boromar Clan** or **House Tarkanan** hideout in Sharn!
